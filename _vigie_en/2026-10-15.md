## 1. ECMWF: watch data access ahead of the 0.1° transition

**Follow-up as of October 15 · Importance: medium.** Users report access difficulties on the forum. These reports are neither an official general-outage notice nor confirmation that 0.1° distribution has launched.

**Why it matters:** a resolution migration needs to be distinguished from an access incident. Automated workflows should support retries and test actual file availability before changing production settings.

**Source:** [ECMWF discussion, dated messages](https://forum.ecmwf.int/t/ecmwf-free-and-open-data-at-9-km-soon-to-come/15366).

## 2. OGC API – Coverages: announced comment deadline

**Deadline: October 15, 2026 · Importance: high for gridded-data APIs.** The Part 1 – Core consultation covers an API supporting domain subsetting, field selection and output resolution. This is a draft under public review, not an announcement of final adoption.

**Why it matters:** weather-grid access needs map directly to subsetting, variable selection and resolution changes.

**Suggested action:** compare the draft requirements with representative weather-data requests and record implementation gaps.

**Source:** [official OGC consultation](https://www.ogc.org/requests/ogc-seeks-public-comment-on-proposed-ogc-api-coverages-part-1-core/).
