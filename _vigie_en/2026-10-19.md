## 1. GDAL: reported anomaly in `gdalwarp -r sum`

**Report dated October 18 · Importance: medium to high depending on the workflow.** The author of issue #15413 reports a roughly 0.27% loss of the total in an EPSG:4326 case using GDAL 3.12.4. The option `-to INSERT_CENTER_LONG=FALSE` restores the expected result in that reproduction.

**Status:** open report; it does not establish that every version or dataset is affected.

**Why it matters:** quantitative aggregation should include conservation checks whenever conservation is expected.

**Suggested action:** reproduce the test with the deployed version and a small representative dataset before adopting a workaround.

**Source:** [GDAL issue #15413](https://github.com/OSGeo/gdal/issues/15413).

## 2. OGC: APIs over low-bandwidth networks

**Consultation open October 9–November 8 · Importance: medium.** The proposed Low Bandwidth & Alternative Transport OGC API working group addresses limited bandwidth, high latency, intermittent links and non-HTTP transports.

**Why it matters:** interoperability also depends on exchange costs and network conditions, particularly for remote and mobile users.

**Suggested action:** document round trips and transfer volumes for a discovery or extraction workflow.

**Source:** [OGC consultation](https://www.ogc.org/requests/low-bandwidth-alternative-transport-ogc-api-dwg/).

## 3. OGC API – EDR: service profiles

**Announced deadline: October 21 · Importance: high for EDR clients.** The proposed Part 3 provides a consistent way to define service profiles, making implementation behaviour more predictable.

**Why it matters:** a profile expresses domain constraints and helps clients discover expected capabilities.

**Suggested action:** compare capabilities needed for a weather use case with the conformance declarations proposed in the draft.

**Source:** [official EDR Part 3 consultation](https://www.ogc.org/requests/ogc-api-edr-part-3-service-profiles-public-comment/).
