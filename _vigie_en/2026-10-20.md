## 1. OGC API – Common Part 4: discovering collections at scale

**Announcement dated October 20 · Comments due November 18 · Importance: high.** Discovery within Many Collections targets APIs exposing hundreds or thousands of collections. It includes text search, paging, spatial and temporal filters, CQL2, sorting and hierarchy.

**Why it matters:** a flat collection list becomes difficult to use as a catalogue grows.

**Suggested action:** compare actual user search criteria with the proposed parameters, then test discovery against a large catalogue.

**Source:** [official OGC consultation](https://www.ogc.org/requests/ogc-seeks-public-comment-on-proposed-ogc-api-common-part-4-discovery-within-many-collections/).

## 2. AIFS-COMPO: AI for atmospheric composition

**ECMWF announcement dated October 16, selected for this edition · Importance: medium to high.** AIFS-COMPO explores aerosol and reactive-gas forecasts up to ten days ahead. The system is experimental; initial charts are available, which does not mean that all underlying data is already distributed.

**Why it matters:** evaluation, available variables and system limitations matter as much as computational speed.

**Suggested action:** examine products and evaluation results before considering integration into an operational workflow.

**Source:** [ECMWF introduction](https://www.ecmwf.int/en/about/media-centre/news/2026/aifs-compo-ai-atmospheric-composition-forecasting).

## 3. GDAL/Zarr: reported inefficiency in downsampled reads

**Report dated October 14, selected for this edition · Importance: medium for remote access.** Issue #15380 describes full-resolution reads before Zarr overviews are used. In the reproduction, the result is correct but transfer volumes are excessive.

**Status:** a user report requiring verification in the relevant environment.

**Why it matters:** a cloud-oriented format alone does not guarantee efficient reads.

**Suggested action:** measure requests and bytes transferred at low zoom levels; compare with direct access to an overview level.

**Source:** [GDAL issue #15380](https://github.com/OSGeo/gdal/issues/15380).
