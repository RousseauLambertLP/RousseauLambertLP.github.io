## 1. GDAL : anomalie signalée avec `gdalwarp -r sum`

**Signalement du 18 octobre · Importance : moyenne à élevée selon les traitements.** L’auteur de l’issue #15413 rapporte une perte d’environ 0,27 % de la somme dans un cas EPSG:4326, avec GDAL 3.12.4. L’option `-to INSERT_CENTER_LONG=FALSE` rétablit le résultat attendu dans sa reproduction.

**Statut :** signalement ouvert; cela ne prouve pas que toutes les versions ou toutes les données sont affectées.

**Pourquoi c’est pertinent :** les agrégations de données quantitatives devraient être accompagnées d’un contrôle de conservation lorsque celui-ci est attendu.

**Piste pratique :** reproduire le test avec la version réellement déployée et un petit jeu de données représentatif avant d’appliquer un contournement.

**Source :** [GDAL issue #15413](https://github.com/OSGeo/gdal/issues/15413).

## 2. OGC : API sur réseaux à faible bande passante

**Consultation ouverte du 9 octobre au 8 novembre · Importance : moyenne.** Le groupe de travail proposé Low Bandwidth & Alternative Transport OGC API vise les réseaux à débit limité, à forte latence, intermittents ou utilisant d’autres transports que HTTP.

**Pourquoi c’est pertinent :** l’interopérabilité dépend aussi du coût des échanges et des conditions réseau, notamment pour les utilisateurs éloignés ou mobiles.

**Piste pratique :** documenter le nombre d’allers-retours et les volumes transférés par un parcours de découverte ou d’extraction.

**Source :** [consultation OGC](https://www.ogc.org/requests/low-bandwidth-alternative-transport-ogc-api-dwg/).

## 3. OGC API – EDR : profils de service

**Échéance annoncée : 21 octobre · Importance : élevée pour les clients EDR.** Le projet Part 3 propose une manière cohérente de définir des profils de service afin de rendre le comportement des implémentations plus prévisible.

**Pourquoi c’est pertinent :** un profil permet d’expliciter les contraintes d’un domaine et aide les clients à découvrir les capacités attendues.

**Piste pratique :** comparer les capacités nécessaires à un usage météo aux déclarations de conformité prévues par le projet.

**Source :** [consultation officielle EDR Part 3](https://www.ogc.org/requests/ogc-api-edr-part-3-service-profiles-public-comment/).
