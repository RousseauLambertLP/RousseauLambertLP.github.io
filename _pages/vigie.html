Une veille orientée vers la pratique

Les annonces officielles, versions publiées, changements intégrés au code et problèmes signalés sont distingués. Une piste de test ou une interprétation est présentée comme telle. Les sources primaires sont privilégiées; les bulletins peuvent être corrigés à mesure que de nouveaux renseignements deviennent disponibles.
